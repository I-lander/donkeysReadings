# Donkeys Readings

AI tarot readings based on the Marseille Tarot. Ask a question, three cards are drawn and an LLM generates the reading.

Stack: Vite + React + TypeScript, Capacitor 6 for the Android app, and a small Express server for the LLM API calls.

## Project layout

- `src/` - the web app (React + TS), bundled by Vite into `dist/`
- `server/` - Express API (`POST /api/generateReading`), calls OpenAI (`gpt-4o-mini`)
- `public/assets/` - card images, fonts, icons
- `android/` - Capacitor Android project (generated by `npx cap add android`)

## Setup

1. Install dependencies

```
npm install
```

2. Copy `.env.sample` to `.env` and set `OPENAI_API_KEY`.

3. Start the API server and the dev server (two terminals)

```
npm run server
npm start
```

Vite proxies `/api` to the local server, open http://localhost:5173.

## Android

The app is a static bundle: it needs a deployed API server. Set `VITE_API_URL` in `.env` to the server URL before building.

```
npm run build:android    # build web + cap sync
npm run open:android     # open in Android Studio
npm run install:android  # build + run on a connected device
npm run build:apk        # release APK
npm run build:bundle     # release AAB (Play Store)
```

## Features

- Shuffles a deck of cards and displays three cards on the screen
- Generates a reading based on the user's question
- Allows users to switch between English and French
- Displays a loading icon while waiting for the reading to be generated
- Screenshot of the reading (download on web, share sheet on Android)
